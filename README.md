## Featured Project

### ScopeAI — Agentic Client Discovery & Project Planning Platform

**LangGraph | Python | FastAPI | Supabase | PostgreSQL | Next.js | React | TypeScript**

ScopeAI is an agentic AI workspace that transforms unstructured client briefs into structured requirements, clarification questions, solution architectures, risk analyses, and implementation roadmaps.

Key engineering highlights:

- Designed a **stateful LangGraph workflow** with specialized nodes and conditional routing.
- Implemented **human-in-the-loop clarification**, allowing the workflow to pause when information is missing and resume after user input.
- Added **controlled tool execution** so LLM reasoning is separated from deterministic validation and database operations.
- Built **FastAPI backend services** for AI workflow execution, LLM integration, and project context management.
- Integrated **Supabase/PostgreSQL** for authentication, persistence, file storage, and Row Level Security.
- Added workflow observability for agent stages, tool calls, interruptions, failures, and generated artifacts.
- Built a supporting **Next.js/React interface** for project dashboards, requirement review, risk analysis, clarification forms, and implementation roadmaps.

## Run Locally

This portfolio is built with plain HTML, CSS, and JavaScript, so no package installation is required.

### Option 1 — Open directly

Open `index.html` in your browser.

### Option 2 — Run with a local server

Using Python:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
